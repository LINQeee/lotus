## Operators

| Operators | Accepted operands | Result |
| --- | --- | --- |
| `+`, `-`, `*`, `/` | Matching numeric types | Same numeric type |
| `%` | Matching integer types | Same integer type |
| `**` | Matching `float` or `double` | Same floating type |
| `<`, `<=`, `>`, `>=` | Matching numeric types | `bool` |
| `==`, `!=` | Matching numeric, boolean or string types | `bool` |
| `&`, `\|` | Two booleans | `bool` |
| `+` | Two strings | Concatenated string |
| Unary `-` | Numeric expression | Same numeric type |

```text arithmetic.lt
print(2 + 3 * 4)
print(7 / 3)
print(-7 % 3)
print(2.0 ** 3.0)
```

```text Output
14
2
-1
8.000000
```

## Precedence

From lowest to highest:

1. `|`
2. `&`
3. Comparisons and equality
4. `+`, `-`
5. `*`, `/`, `%`
6. `**`
7. Casts, unary minus and primary expressions

Binary operators at the same precedence associate left to right, **including power**. Use parentheses to express another grouping.

```text grouping.lt
print(2.0 ** 3.0 ** 2.0)
print(-2.0 ** 2.0)
print(-(2.0 ** 2.0))
```

```text Output
64.000000
4.000000
-4.000000
```

<Warning>
Boolean `&` and `|` evaluate both operands. They do not short-circuit. `!` currently marks an excluded range boundary, not logical negation.
</Warning>

Unary minus supports variables, grouped expressions and calls; its operand is evaluated once.
