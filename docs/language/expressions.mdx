## Operators

| Operators | Accepted operands | Result |
| --- | --- | --- |
| `+`, `-`, `*`, `/` | Matching numeric types | Same numeric type |
| `%` | Matching integer types | Same integer type |
| `**` | Matching `float` or `double` | Same floating type |
| `<`, `<=`, `>`, `>=` | Matching numeric types | `bool` |
| `==`, `!=` | Matching numeric, boolean or string types | `bool` |
| `&`, `\|` | Two booleans | `bool` |
| `+` | Two strings | Concatenated string |
| Unary `-` | Numeric expression | Same numeric type |
| Unary `!` | Boolean expression | Inverted `bool` |
| `++`, `--` | Numeric variable | Same numeric type |

```rust arithmetic.lt
print(2 + 3 * 4)
print(7 / 3)
print(-7 % 3)
print(2.0 ** 3.0)
```

```text Output
14
2
-1
8.000000
```

## Precedence

From lowest to highest:

1. `|`
2. `&`
3. Comparisons and equality
4. `+`, `-`
5. `*`, `/`, `%`
6. `**`
7. Casts and prefix `-`, `!`, `++`, `--`
8. Postfix `++`, `--` and primary expressions

Binary operators at the same precedence associate left to right, **including power**. Use parentheses to express another grouping.

```rust grouping.lt
print(2.0 ** 3.0 ** 2.0)
print(-2.0 ** 2.0)
print(-(2.0 ** 2.0))
```

```text Output
64.000000
4.000000
-4.000000
```

<Warning>
Boolean `&` and `|` evaluate both operands. They do not short-circuit.
</Warning>

## Logical negation

```rust logical-not.lt
bool enabled = true
print(!enabled)
print(!!enabled)
print(!(2 == 3))
```

```text Output
false
true
true
```

`!` requires `bool`; numbers and strings are not converted implicitly. Unary `!` and `-` evaluate their operand once and bind tighter than binary operators. Beside `..` in a range, `!` still [excludes a boundary](/language/control-flow#include-or-exclude-boundaries).


## Increment and decrement

`++` adds one; `--` subtracts one. Prefix returns the updated value; postfix returns the old value. Both update the variable immediately.

```rust update.lt
int x = 1
print(++x) // 2, x = 2
print(x++) // 2, x = 3
print(--x) // 2, x = 2
print(x--) // 2, x = 1
```

Only `int`, `long`, `float` and `double` variables are accepted. Literals, calls and computed expressions cannot be updated. Postfix operators must be on the same line as their operand. Write `-(-x)` for double negation: `--x` decrements `x`.
