## Conditions

`if` and `while` require a `bool`. Braces are optional for one statement.

```rust branches.lt
int value = 3
if value > 0 print("positive")
else print("non-positive")

while value > 0 {
    print(value)
    value -= 1
}
```

```text Output
positive
3
2
1
```

## Range loops

```rust ranges.lt
for i in 1..3 print(i)
for i in 3..1 print(i)
```

```text Output
1
2
3
3
2
1
```

The counter type is inferred from the bounds: both must be `int`, or both `long`. Bounds are evaluated once, left to right. Parentheses around `i in ...` are optional.

### Include or exclude boundaries

`..` includes both ends. Put `!` next to a boundary to move it **one integer inward**, independently of the step.

| Range | Values with the default step |
| --- | --- |
| `1..4` | `1, 2, 3, 4` |
| `1!..4` | `2, 3, 4` |
| `1..!4` | `1, 2, 3` |
| `1!..!4` | `2, 3` |
| `4!..!1` | `3, 2` |

Equal included bounds produce one iteration. Excluding an equal bound, or crossing the bounds after exclusion, produces an empty range.

### Choose a step

```rust steps.lt
for i in 0!..5 step 2 print(i)
for i in 5!..0 step -2 print(i)
```

```text Output
1
3
5
4
2
0
```

- Default: `+1` if the original start is below the end, otherwise `-1`.
- Explicit step: a nonzero integer literal of the range type, such as `2` or `-2L`.
- A step pointing away from the end produces an empty loop.
- Generated advancement handles integer limits without wrapping the counter.

### Change the counter

```rust mutable-counter.lt
for i in 0..5 {
    print(i)
    if i == 0 i = 3
}
```

```text Output
0
4
5
```

After the body or `continue`, the fixed step is added to the current counter. Assignments do not recompute bounds or direction. Moving backward can repeat iterations indefinitely.

## Break and continue

| Statement | Action |
| --- | --- |
| `break` | Exit the nearest loop |
| `continue` or `next` | Start its next iteration |
| `break @2` | Exit two nested loops |
| `continue @2` | Continue the enclosing loop two levels out |

Levels count both `for` and `while`. Invalid levels are rejected.

<Note>
Ranges exist only in `for` headers; they cannot be stored as values. Steps cannot be variables or runtime expressions.
</Note>
