---
title: "Lotus"
description: "A concise, statically typed language with LLVM execution."
---

Write explicit types, small functions and range loops. Run them through LLVM and use native C functions when needed.

```text hello.lt
fn sum(a: int, b: int): int {
    return a + b
}

print(sum(20, 22))
```

```text Output
42
```
