Lotus is an experimental, statically typed language implemented with LLVM and a native C runtime.

  <Card title="Get started" icon="terminal" href="/quickstart">

  </Card>

    Types, variables, functions, loops and strings.
  </Card>
  <Card title="Contribute" icon="code-pull-request" href="/development/workflow">
    Set up checks, write tests or extend the compiler.
  </Card>
</Columns>

```rust hello.lt
fn sum(a: int, b: int): int {
    return a + b
}

print(sum(20, 22))
```

```text Output
42
```

<Note>
Lotus is pre-alpha. Syntax and the native ABI may change. Check [current support](/status) before choosing it for a project.
</Note>
