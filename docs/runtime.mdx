---
title: "Runtime functions"
description: "The functions registered by lotus-core."
---

Build and load `lotus-core` alongside the compiler. Functions below are available without imports.

| Function | Result | Behavior |
| --- | --- | --- |
| `print(values...)` | void | Concatenates printed values, then adds a newline; at least one argument |
| `input()` | `string` | Reads through newline or EOF; omits the newline |
| `toInt(text: string)` | `int` | Uses C `atoi`; not a checked parsing API |
| `toBool(value: any)` | `bool` | Conversion rules below |
| `randomNum(min: int, max: int)` | `int` | Inclusive bounds; provide a valid non-overflowing range |

```text runtime.lt
print("sum=", 1 + 2 + 3)
print(1.5 + 2.25)
print(toInt("42"))
```

```text Output
sum=6
3.750000
42
```

## Printing and input

`print` adds no separators between arguments. Floats use six decimal places. Empty input and EOF return an empty string; an embedded NUL stops printed string output even though string equality remains length-aware.

## Boolean conversion

| Input | Result |
| --- | --- |
| Numeric value | `true` only when greater than zero |
| `bool` | Unchanged |
| String `"true"` or `"false"` | Corresponding boolean |
| Another string | Diagnostic on stderr and `false` |

## Runtime helpers

`_concat(string, string)` and `_stringEquals(string, string)` implement concatenation and equality. Prefer the language operators. `_stringRetain` and `_stringRelease` are reserved for generated/native code and cannot be called from Lotus.

<Warning>
`randomNum` reseeds from the current time on every call. It is a prototype helper, not a source of reproducible or secure randomness. `toInt` does not report invalid input or overflow reliably.
</Warning>
