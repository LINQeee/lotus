description: "What works today and what is not implemented yet."
---

Lotus is pre-alpha. Use the supported constructs below; syntax and the native ABI can change.

| Available | Not implemented |
| --- | --- |
| Six primitive types and explicit numeric casts | Arrays, structs and generics |
| Top-level functions and recursion | Nested functions and closures |
| Conditions, while loops and range loops | Iterable collections and range values |
| Automatic string reference counting | General garbage collection |
| Native C libraries and LLVM JIT execution | A supported standalone executable workflow |
| Feature tests and local benchmarks | Source-file CLI arguments and module imports |

The current backend and test runtime target macOS. String ARC does not imply complete compiler-memory cleanup; see [testing boundaries](/development/tests#coverage).
