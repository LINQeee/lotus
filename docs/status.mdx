title: "Current support"
description: "Implemented features and current limits."
keywords: ["Lotus", "status"]
---

Lotus is pre-alpha; syntax and the native ABI may change. Installers target 64-bit macOS, Linux and Windows (MSYS2 Clang64).

macOS Apple Silicon has been tested locally. Windows, Linux and Intel macOS require successful platform CI runs before release.

| Available | Not implemented |
| --- | --- |
| Explicit types and numeric casts | Implicit conversions, generics |
| Classes, per-instance field defaults and methods | Object shapes, spread, inheritance and recursive fields |
| Top-level functions and recursion | Nested functions and closures |
| Conditions, while, range and array loops | Range values and dynamic lists |
| Strings and fixed-length arrays with automatic reference counting | Nested arrays, string indexing and Unicode normalization |
| JIT execution and executable builds | REPL, cross-compilation and bundled distributions |
| Native C extensions | `.lt` module imports and package management |

Executable builds require [native libraries](/cli#executable-builds).
