## Install

Run one command below — no repository clone or manual download is needed. The installer downloads the sources into a temporary folder, installs dependencies, builds Lotus and lotus-core, then adds `lotus` to your terminal's `PATH`.

System permissions may still require a password or Windows elevation. Keep LLVM and the installed toolchain available after setup.

<Tabs>
<Tab title="macOS">

Requires [Homebrew](https://brew.sh) and its Command Line Tools prerequisite. Apple Silicon and Intel builds use the same command:

```sh
curl -fsSL https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.sh | bash
```

Installs dependencies with Homebrew and Lotus into `~/.local/share/lotus`. Open a new terminal afterward.

[View the Bash installer](https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.sh)

</Tab>
<Tab title="Linux">

On Debian/Ubuntu, the installer uses `sudo`, apt and the [LLVM package repository](https://apt.llvm.org):

```sh
curl -fsSL https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.sh | bash
```

Installs Lotus into `~/.local/share/lotus`. Open a new terminal afterward. On other distributions, install LLVM 22+, CMake 3.25+, Ninja, Git and Clang first, then append `-s -- --no-deps` to `bash`.

[View the Bash installer](https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.sh)

</Tab>
<Tab title="Windows">

Requires Windows 10 1903+ or Windows 11, x64, PowerShell and `winget`:

```powershell
irm https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.ps1 | iex
```

Installs MSYS2/Clang64 dependencies and Lotus into `%LOCALAPPDATA%\Lotus`. The `lotus` launcher works in PowerShell and cmd without opening an MSYS2 shell. New terminals inherit the command from your user `PATH`.

[View the PowerShell installer](https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.ps1)

</Tab>
</Tabs>

## Run a program

```sh
lotus new hello-world .
lotus run hello-world/main.lt
```

```text Output
Hello, World!
```

Edit `hello-world/main.lt` to write your program. `run` executes immediately through JIT. `lotus build hello-world/main.lt` creates `main.lt.out` on macOS/Linux or `main.lt.exe` on Windows beside the source, without executing it. See [native library requirements](/cli#executable-builds) before sharing the binary.

## Install from a checkout

Initialize the submodules first. From the repository root:

```sh
bash scripts/install.sh --source .
```

On Windows:

```powershell
& ./scripts/install.ps1 -Source .
```

| Option | Bash | PowerShell |
| --- | --- | --- |
| Installation directory | `--prefix DIR` | `-Prefix DIR` |
| Existing dependencies | `--no-deps` | `-NoDeps` |
| Leave shell/PATH settings alone | `--no-path` | `-NoPath` |

For a custom toolchain, set `LLVM_DIR`, `CC`, `CXX` and `CMAKE` before running the Bash installer. On Windows, `-MsysRoot DIR` selects an existing MSYS2 installation. Rerun the installer to update Lotus; it builds the current `main` branch unless `LOTUS_REF` selects another branch or tag.
