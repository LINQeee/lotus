## Choose your OS

<Tabs>
<Tab title="macOS">

Requires [Homebrew](https://brew.sh) and Command Line Tools.

```sh
curl -fsSL https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.sh | bash
```

Installs Lotus into `~/.local/share/lotus`.

</Tab>
<Tab title="Linux">

For Debian and Ubuntu:

```sh
curl -fsSL https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.sh | bash
```

Installs Lotus into `~/.local/share/lotus`. For other distributions, see [build from source](/development/build#dependencies).

</Tab>
<Tab title="Windows">

Requires Windows 10 1903+ or Windows 11, x64, PowerShell and `winget`:

```powershell
irm https://raw.githubusercontent.com/LINQeee/lotus/main/scripts/install.ps1 | iex
```

Installs Lotus into `%LOCALAPPDATA%\Lotus`.

</Tab>
</Tabs>

## Run a program

In a new terminal:

```sh
lotus new hello-world .
lotus run hello-world/main.lt
```

```text Output
Hello, World!
```
