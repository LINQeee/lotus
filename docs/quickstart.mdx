## Requirements

- macOS and a C11 compiler such as Clang
- CMake 4.2+ for the compiler and runtime
- LLVM 22 development installation

## Build from source

```sh
git clone --recurse-submodules https://github.com/LINQeee/lotus.git
cd lotus
cmake -S . -B cmake-build-debug
cmake --build cmake-build-debug --target compiler
cmake -S lotus-core -B lotus-core/cmake-build-debug
cmake --build lotus-core/cmake-build-debug --target lotus_core
```

If LLVM is not found, add `-DLLVM_DIR=/path/to/llvm/lib/cmake/llvm` to the first CMake command. For an existing clone, initialize dependencies with `git submodule update --init --recursive`.

## Run a program

Create `hello.lt`:

```rust hello.lt
for i in 1..3 print(i)
```

Run it from the repository root:

```sh
./cmake-build-debug/lotus run hello.lt
```

```text Output
1
2
3
```

`run` executes through JIT. To create a binary instead:

```sh
./cmake-build-debug/lotus build hello.lt
./hello.lt.out
```

`build` creates the file without running it. The binary still needs its native runtime libraries.

## Install the command

```sh
cmake --install cmake-build-debug --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
lotus run hello.lt
```

Only the `lotus` executable is installed. Keep LLVM and the checkout's `libs/` directory available; see [runtime paths](/cli#native-libraries) before moving them.
